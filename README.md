
# 🌿 Cannabis Therapy — AI-Powered Digital Therapeutic Platform

**Live:** https://weed-therapy.vercel.app/ | **Stack:** React · Node.js · Express · MongoDB · Google Gemini · JWT · Tailwind CSS

---

Cannabis Therapy is a full-stack digital therapeutic platform engineered for cannabis harm reduction and structured recovery. It moves beyond a simple chatbot to deliver a clinically-inspired system: multi-modal AI therapy sessions, longitudinal recovery analytics, a personalised tapering plan engine, drug interaction screening, CUD self-assessment, and real-time strain recommendations — all secured behind JWT authentication and served through a RESTful API.

## Features

### 💬 Multi-Modal AI Therapy Sessions
- Users select a structured session type before every conversation — the AI prompt template, tone, and guidance strategy adapt accordingly
- Session types: **General Therapy, Craving Emergency, Stress Coping, Mood Regulation, Grounding/Mindfulness, Relapse Reflection, Guided Reflection, Daily Journal, Habit Builder**
- Session lifecycle managed via dedicated controller: `start → continue → end → summarise`
- AI responses follow a structured therapeutic format: **Acknowledge → Normalise → Suggest → Reassure**
- Session summaries auto-generated by Gemini on close
- Anonymous mode: sessions stored without personal identifiers; UI surfaces clear anon indicators

### ✅ Daily Check-In System
- Structured intake form: mood, craving, stress, and energy (0–10 sliders) + free-text notes
- Smart once-per-day popup using combined backend state + user-scoped `localStorage` keys (prevents cross-account leaking)
- Gemini generates a personalised emotional summary per check-in entry
- Edit endpoint for correcting past entries
- 7-day mood sparkline rendered without a chart library (pure CSS/JS)
- Consecutive-day streak counter computed server-side

### 📊 Recovery Analytics Dashboard
- **Recharts** time-series visualisations for mood, craving, and stress trends
- Good days vs bad days classification with configurable thresholds
- **Pearson correlation** computed server-side to surface trigger patterns (e.g., stress → craving spikes)
- Three advanced metrics derived from check-in history:
  - **Check-In Quality Score** — consistency and completeness of entries
  - **Mood Stability Index** — variance-based emotional stability rating
  - **Coping Effectiveness Score** — correlation between coping activities and mood improvement
- Gemini-generated narrative insights for **weekly**, **monthly**, and **all-time** ranges
- All aggregation logic handled server-side via Mongoose helper functions (`buildDateRange`, `mean`, `pearsonCorrelation`, `computeInsightsForRange`)

### 📉 Tapering Plan Engine (T-Plan)
- AI-generated personalised cannabis reduction schedule based on current usage, goals, and session history
- Mongoose model: `TPlan` — stores `weeklyTargets[]`, `progressLogs[]`, plan metadata, and `aiRefinement` string
- Weekly target schema with `startDate`, `endDate`, `targetUsage`, and `notes`
- Progress log schema: `actualUsage`, `mood`, `source` (`manual` | `checkin`), `notes`
- `GET /api/tplan/active` returns a fully enriched response: today's target, weekly progress %, streak, and full log history
- Server-side streak computation from `progressLogs`
- Plan status lifecycle: `active → paused → completed`
- Auto-sync: progress logs can be sourced from daily check-in data
- Animated circular progress rings and tab-based UI (Home · Schedule · History · Settings)

### 🌿 AI Strain Recommender
- Triggered from the global header — accessible on every page
- Fetches the user's most recent `DailyCheckin` document and passes mood, craving, stress, and energy to Gemini
- Returns 3 structured recommendations: **2 non-cannabis alternatives + 1 strain option**
- Automatically prioritises non-cannabis alternatives when craving ≥ 7 or session type is `craving_emergency`
- Each recommendation includes: name, rationale, safety notes, and harm-reduction guidance
- Medical disclaimer rendered prominently in the modal UI

### 💊 Drug Interaction Checker
- Dedicated `/interaction` route and controller
- Users input current medications; Gemini returns structured cannabis interaction safety alerts
- Covers interactions with anticoagulants, SSRIs, antiepileptics, cardiovascular medications, and more
- Results include severity classification and recommended actions

### 🧪 CUD Screening
- Structured Cannabis Use Disorder self-assessment at `/screening`
- Questionnaire responses submitted to backend; Gemini scores severity and generates personalised guidance
- Results persisted to `CUDScreening` collection with timestamps
- Severity classifications: minimal / mild / moderate / severe
- Explicit disclaimer: for personal awareness only, not a clinical diagnosis

### 💨 Know Your Dose
- Consumption tracker at `/dose`
- Logs method, potency, and frequency per session
- Contextual education on modern cannabis potency and safe consumption thresholds
- Designed to support informed, harm-reduction-oriented use

### 🎙️ Voice Input
- Web Speech API integration for speech-to-text inside the therapy chat
- Non-blocking implementation — runs independently of the main UI thread

## Optimisations

- Lazy-loaded chat logs and check-in history to reduce initial bundle impact
- Optimistic UI for message sending with streaming-style typing indicators
- Auto-scroll tuned to avoid layout jank on long sessions
- Web Speech API runs off the main thread — no UI blocking during voice input
- Dual visual theme: calming greens/neutrals for wellness pages; dark zinc/slate for T-Plan
- Mobile-first layout with sticky session controls and bottom navigation on small screens

---

## Security

- JWT access + refresh token pair with short-lived access tokens
- HTTP-only cookie handling for refresh tokens
- User-scoped resource access enforced at controller level (no cross-user data leakage)
- Per-user `localStorage` namespacing for client-side state
- Input sanitisation middleware on all write endpoints
- AI safety filters and crisis escalation language built into all therapy prompt templates

## Lessons Learned

- **Production LLM Architecture** — Designed a multi-purpose Gemini integration with prompt templating, safety guardrails, token tracking, and structured output parsing across 7 feature areas from a single API client
- **Secure Personalisation at Scale** — Balanced deep emotional personalisation with privacy: scoped JWT auth, per-user storage keys, and encryption-at-rest for sensitive content
- **AI Ethics in Digital Health** — Built flows that encourage self-regulation and reflection, include appropriate crisis escalation language, and explicitly avoid clinical diagnosis framing
- **Digital Therapeutic Systems Design** — Evolved a simple chatbot into a structured therapeutic platform with session typing, longitudinal analytics, tapering plans, and harm-reduction tooling
- **Full-Stack Modularity** — Maintained clean separation between UI, services, and controllers throughout rapid feature iteration; architecture is multi-client ready (web + React Native)
